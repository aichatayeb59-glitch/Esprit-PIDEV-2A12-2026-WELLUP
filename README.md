# WellUp – Health and Wellness Web Application

> **Beyond Words** — Small habits, better life.

## Overview
WellUp is a web application designed to help users improve their daily lifestyle through simple and healthy habits. It focuses on health, wellness, hydration, physical activity, and mental well-being.

This project was developed as part of the PIDEV – 2nd Year Engineering Program at **Esprit School of Engineering – Tunisia** (Academic Year 2026–2027).

## Features
- Water consumption tracking
- Physical activity tracking
- Daily mood journal
- Personal goals management
- Health and wellness advice
- Advice and categories management (CRUD)
- AI-powered daily recommendations
- User accounts and role management
- Administration and general statistics

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- PHP
- XAMPP(Apache)
- MySQL

## Architecture
The application follows the **Model-View-Controller (MVC)** architecture. It separates application logic, user interface, and data management.

## Getting Started

### Prerequisites
- XAMPP (Apache + MySQL)
- PHP
- A web browser

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/aichatayeb59-glitch/Esprit-PIDEV-2A12-2026-WELLUP.git
   ```
2. Move the project folder to the `htdocs` directory of XAMPP (`C:\xampp\htdocs\wellup`).
3. Start **Apache** and **MySQL** from the XAMPP Control Panel.
4. Open **phpMyAdmin** (`http://localhost/phpmyadmin`), create a database, and import the `database.sql` file.
5. Open the application in your browser: `http://localhost/wellup`
